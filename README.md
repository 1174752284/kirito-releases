软件内更新
安装已接入更新服务的版本后，可点击顶部版本号或“设置 → 检查更新”。
发现新版本后点击“立即更新”，软件会下载、校验、备份旧程序并安装。
原来未接入更新地址的版本，需要先手动安装接入版一次。

版本说明以各 Release 公告为准。更新包有作者签名及文件校验。
